# Fonts and icons

Fonts (SIL Open Font License 1.1, license files in this folder), from github.com/google/fonts:
Barlow Condensed Bold, Barlow Regular, IBM Plex Mono Regular. Embedded subset as WOFF2.

Icons, extracted from the react-icons 5.7.0 package:
- Simple Icons (CC0 1.0): Spring Boot, OpenJDK (Java), Flutter, Dart, Apache Kafka, Docker, Kubernetes, PostgreSQL, MongoDB, NestJS, Figma.
- Font Awesome Free (CC BY 4.0): AWS, LinkedIn, globe, open book. Simple Icons does not include the AWS and LinkedIn marks.
- Game Icons (CC BY 3.0): tank.
- Material Design Icons (Apache 2.0): cricket.

All product names and logos belong to their owners.
